## Featured Projects

### 🤖 AgDashboard — Solana DEX Automated Trading Engine
> *The most complex system I've built. Production-grade, real money.*

A full-stack automated trading platform for Solana DEX tokens — 62K+ LOC across .NET 10 backend and Angular 21 frontend.

**What it does:** Runs 100+ simultaneous trading strategies across multiple wallets, executes swaps via Jupiter Aggregator with MEV protection (Jito bundles), manages risk with per-wallet and daily loss limits, and recovers from partial failures via a write-ahead transaction journal.

**Technical highlights:**
- Multi-layer concurrency: `sp_getapplock` per-strategy + per-coin, `SemaphoreSlim` per-wallet
- WAL (Write-Ahead Log) pattern: `TransactionJournal` entity written before any on-chain submission — zero ghost positions
- AES-256-GCM wallet key encryption (PBKDF2 600K iterations, NSec Ed25519 signing)
- 16 Hangfire background jobs, real-time SignalR dashboard, Telegram trade alerts
- Azure AI Foundry GPT-4o integration for token research
